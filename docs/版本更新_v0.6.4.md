# v0.6.4 版本更新摘要

## 修复：词缀数据分类与官网对不上（核心数据修复）

**问题**：暗金词条自动填写时，部分词条的官方下拉文本与市集官网真实下拉不一致，导致选错下拉项或选不中。典型案例：**寒冬噬咬 玻璃利片** 的冰霜词条，此前填写「该装备附加 # - # 基础冰霜伤害 (区域)」，正确应为「**附加 # - # 冰霜伤害**」。

**根因**：词缀映射库（official_stat_map）此前用官方 API 文本反查生成，而 **API 文本 ≠ 市集下拉文本**——同一个属性 ID，API 给出「该装备附加 # - # 基础冰霜伤害 (区域)」，市集下拉实际显示「附加 # - # 冰霜伤害」；旧数据还用了模糊包含匹配兜底，共造成 **49 条文本映射到错误属性 ID**。

**修复内容**：
1. **重建词缀映射库**：显示文本一律以市集真实抓取的 496 条下拉为准，属性 ID 以市集页面状态数据（peer）为准，同义词精确匹配、**禁用模糊包含兜底**，匹配不上如实记录（108 条）而不猜。
2. **本地词缀重定向升级**：重定向候选只认市集真实下拉文本，API 伪形态（带「(区域)」后缀但下拉里不存在的文本）彻底出局；69 条武器附加伤害词条全部精确命中正确下拉。
3. **连带修正**：白银之舌的生命/魔力偷取属性 ID 纠正为市集正确项；尼布洛克、怨怒塔矛的混沌附加补登市集下拉文本。
4. **回归断言**：E2E 新增寒冬噬咬专项断言（文本「附加 # - # 冰霜伤害」+ 属性 ID 1037193709，且不得是反击技能 ID）。

**验证**：verify_local_redirect 21/21 · verify_unique_mods 25/25 · verify_wysiwyc 7/7 · verify_tabs 34/34 全部通过。

**数据规模**：映射 389 条（49 条错映射清零）· 暗金 2768 个 / 词条 14145 条 / 可筛 12097 条 · local 重定向 282 条文本 100% 为市集真实下拉。
