# 版本更新 v0.8.1 — 词条数据补全：全量展示 + 灰显参考

> 2026-09-15/16 · 针对「武器词条热度只有 3 条，一个武器至少 6 词缀，应该全部列出来」的反馈

## 问题

进阶模式词条榜之前只显示「statIds 与 mods_db 词缀池有交集」的词条，两处保守过滤导致大量真实词条被丢弃：

1. **对齐失败被丢弃**：ninja 英文模板 → GGG stats（POE1 词库）对不上的直接不进榜。但其中很多是国服市集真实可筛的词条（药剂自动使用系、暴伤、召唤生物、友军光环、投射物技能等级等），只是 GGG POE1 词库里没有。
2. **mods_db 词缀池稀疏误杀**：mods_db 有 841 个词缀组 statIds 为空（药剂充能、咒符充能等真实可筛组），池交集过滤把能筛的词条也判成不可筛。

## 修复

### 数据链路（scripts/build_builds_db.js）

- **可筛判定改为「stat_id 在国服市集官方 stat 宇宙（trade2_stats_flat，4754 条）内」**：市集填表本身走「官方文本搜索下拉」，不依赖 mods_db 分组，所以对齐到官方 stat 就能填。
- **CN_DIRECT 国服直译表扩容**（19 → 100+ 条）：药剂自动使用全家族（被点燃时/陷入冻结时/当你被晕眩时…）、使用时回复生命/魔力、暴伤/法术暴击、感电/点燃/易燃强度、冻结积蓄、召唤生物 6 条、在场的友军 11 条、药剂充能 4 条、榴弹、翻滚距离、技能品质等。**全部文本逐一在 trade2_stats_flat 验证过存在**。
- **alignMod 双通道兜底**：GGG 命中但无中文（POE1 旧 id，国服换 id）时，用 CN_DIRECT 中文模板反查 trade2 id 并入 statIds。
- 语义不对应的不做映射（宁缺毋滥）：`reduced Amount Recovered`（减≠增）、`per Power Charge`（每球≠平铺）等走灰显参考。

全库 1295 条词条：可筛 1252（**96.7%**）+ 灰显参考 43（修复前可筛仅 840 / 64.9%）。

### UI（popup.js / popup.html）

- **全量展示**：词条榜不再剔除对不齐的词条，灰显（虚线边框 + 「参」标）展示，tooltip 说明「市集暂无此筛选项，仅展示热度参考」。
- **直填通道**：词条点亮后若 mods_db 无对应词缀组、但 statIds 对齐官方 stat，按市集官方文本直接搜索下拉填表（不再报「不支持筛选」）。
- 灰显词条点亮仍只作标记，**不进填表 payload**。
