# 版本更新 v0.8.2 — 官方文本对齐国服市集真名 + 兜底探测

> 2026-09-16 · 针对「词缀「该装备的攻击暴击率提高 #%」下拉未命中」「攻击速度提高…词条的匹配没有对齐国服的词条」的反馈

## 问题

实填武器（邪恶节杖）时两条词条填不进：

1. 「该装备的攻击暴击率提高 #%」下拉未命中 —— 这句是 **POE1 旧 stat 文本**（stat_2375316951），国服市集根本没这个下拉项，真实可筛的是「攻击暴击率提高 #%」（stat_2194114101）。
2. 「攻击速度提高 #%」—— 市集真名是「攻击速度加快 #%」。搜「攻击速度提高」上次蒙对了（误中「战矛的攻击速度提高 #%」），但根因没除。

量化排查：mods_db 全库 **760 个词缀组 + 3172 条暗金词条**的 officialText 不在国服市集文本宇宙（trade2_stats_flat 4754 条）里。

## 修复

### ① 数据侧：fix_official_text.js（幂等修正）

按优先级修正 mods_db 的 officialText：

- 已在市集文本宇宙 → 跳过
- statIds 反查 trade2 真名（explicit 优先）→ 修 531 组
- CN_FIX 静态纠错表（21+ 条，逐一探针验证过市集存在）→ 修 86 组
- 都救不回（市集已移除的旧词条，外延系 131 + 植物/变形/充能 12）→ 打 `_noTrade` 标记

暗金词条同样处理：修正 3035 条 + 137 条打标。

CN_FIX 关键映射举例：
`该装备的攻击暴击率提高 #% → 攻击暴击率提高 #%`、`攻击速度提高 #% → 攻击速度加快 #%`、
`暴击率提高 #% → 攻击暴击率提高 #%`、`品质上限 #% → 品质上限为 #%`、`# 生命上限 → # 最大生命`、
`在你格挡时获得#生命 → 生命在你格挡时 #%`、`击败敌人时有 #% 的几率获得一个能量球 → 击败敌人时有 #% 的几率获得一次充能` 等。

### ② 构建侧：build_builds_db.js（进阶词条榜不再产生旧措辞）

- alignMod 中文对齐改为**市集文本优先**：idToCn 命中的文本若不在市集宇宙，先试其他 stat_id 的 trade2 文本。
- 新增 CN_OVERRIDE 强制改写表（该装备的攻击暴击率/物理伤害/攻击速度/施法速度/暴击率 5 条），改写后并入真名对应的 trade2 id。
- 重建后全库 1295 条词条 cn 全部落入市集宇宙，**0 条例外**。

### ③ 填表侧：content.js searchPickFallback 兜底探测（最后防线）

数据修完后仍有长尾风险（暗金词条措辞漂移等），首搜未命中时兜底：

- **候选词生成**：整段 → 去 POE1 前缀（该装备的/你的/…）→ 去动词尾（提高→加快场景）→ 滑窗头尾去字，最短 4 字（防「提高」泛词）。
- **LCS 相关性选优**：每个候选词重搜后，对全部可见选项按「选项签名与 probe 签名的最长公共子串」打分，超过阈值（max(4, 签名长−6)）才选最佳项 —— 限定变体（如「攻击速度加快 #% (区域)」）放行，无关词条拒绝。
- 旧实现按非中英切段，遇到「该装备的攻击暴击率提高 #%」这种**整句连续中文段**没有更短候选，兜底等于没兜 —— 已重写。

### ④ UI 侧：popup.js

- `_noTrade` 词缀组在面板中禁用，标注「（市集已无此筛选项）」，不再进填表 payload。
