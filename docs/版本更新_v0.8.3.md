## 管线修复（3 个 bug）

1. **E2E 假死**：`update_db.js` 内置 8642 服务器 + `spawnSync` 跑 verify，同步阻塞事件循环导致服务器无法响应，mock 页 `ERR_CONNECTION_REFUSED`、4 套 E2E 误报 3 挂。改为异步 `spawn` + 逐例汇报。
2. **进阶模式基底中文名丢失**：`build_builds_db.js` 普通基底中文名只查 mods_db——官网基准过滤后 mods_db 仅剩 63 个基底，天梯普通装备 86% `cn=null`（进阶模式显示英文、base 带出失败）。改为 **data/base_panels.json（1800+ 全量）优先 → mods_db 兜底**，cn=null 归零（414/414 有中文）。
3. **`--skip` 续跑陷阱**：备份逻辑无条件把 `data/ninja` 旧产物挪进备份，`--skip=ninja` 续跑时 `build_builds_db.js` 无输入报错。改为仅 ninja 步骤会执行时才挪。

## 升级方式
