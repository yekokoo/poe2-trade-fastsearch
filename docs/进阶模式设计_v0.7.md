# 进阶模式设计（v0.7.0）

> 状态：设计稿，待确认。上游探测结论见 `.workbuddy/memory/2026-09-10.md` #39。

## 1. 一句话

在现有面板上加「经典 / 进阶」切换。进阶模式 = 选职业 → 升华职业 → 流派 → 装备类型 → 点亮流行装备与词条 chips → 一键填入市集搜索。数据来自 poe.ninja 最新赛季 builds，离线打包在 `builds_db.json`。

## 2. 数据链路（#39 探测定论）

| 环节 | 方式 | 说明 |
|------|------|------|
| 赛季/版本 | `GET /poe2/api/data/index-state` | 取 buildLeagues + snapshotVersion（url/snapshotName/version） |
| 升华职业人气 | `GET /poe2/api/data/build-index-state` | statistics[{class, percentage}]，31 个升华职业 |
| 部位装备榜 Top20 | 浏览器渲染列表页（playwright-core） | ITEMS 区部位过滤 select → 「稀有度+名称+占比」 |
| 每构建装备+词条 | `GET /poe2/api/builds/{version}/character?account=&name=&overview={snapshotName}` | 纯 HTTP JSON：items[].itemData{inventoryId, frameTypeId, baseType, name, explicitMods, implicitMods}、skills[]（主技能=流派） |
| 词条聚合 | 本地统计 explicitMods 模板计数 | 英文模板 → 对齐 mods_db affixGroups（statIds 桥）→ 中文/T级/官方文本直接复用 |
| 暗金映射 | data/tmp/unique_name_map.json（487 条） | ninja 英文名 → mods_db U_* 暗金 → 点亮自动带固定词条 |

抓取量估算：31 升华职业 × Top100 构建 × ~330KB ≈ 1GB 流量（一次性，可分批）；聚合产物每升华职业约 200KB。

## 3. builds_db.json 结构

```jsonc
{
  "version": "0.1.0",
  "builtAt": 1757466000000,
  "league": { "url": "forbiddenrites", "snapshotName": "forbidden-rites",
              "snapshotVersion": "0821-20260914-49179", "label": "禁诫权仪" },
  "classes": [ { "cn": "佣兵", "en": "Mercenary", "asc": ["Gemling Legionnaire"] } ],
  "asc": {
    "Gemling Legionnaire": {
      "class": "Mercenary", "popPct": 37.8, "buildsSampled": 100,
      "skills": [ { "en": "Oil Grenade", "cn": "燃油榴弹", "pct": 41 } ],   // 流派榜
      "slots": {
        "Ring": {
          "cn": "戒指", "baseSlugs": ["Rings"], "share": 97,
          "items": [
            { "rarity": "rare", "en": "Rare Ring", "cn": "稀有戒指", "pct": 97,
              "mods": [ { "pct": 78, "groupId": "prefix|+#生命上限" } ] },   // 指回 mods_db
            { "rarity": "unique", "en": "The Taming", "cn": "驯服 双玉戒指",
              "pct": 25, "uSlug": "U_17" }                                    // 指回 mods_db 暗金
          ]
        }
      }
    }
  }
}
```

要点：
- **词条只存 `groupId` 指回 mods_db**（如 `prefix|+#生命上限`），popup 选中后走现有 `currentAffixes()` 链路（官方文本/T 级/statIds 全部复用），零新增填表逻辑。
- **文件拆分**：`builds_db.json`（索引+职业/流派榜，~50KB）+ `builds_shards/{AscSlug}.json`（各升华职业 slots 详情，按需 fetch），避免面板一次拉 6MB。

## 4. 交互设计

```
┌ P2 市集速搜  [经典|进阶]  builds v0.1 · 禁诫权仪 ┐
│ ① 职业（7 基础职业，本地静态映射升华归属）        │
│ ② 升华职业（2~4 项，带 ninja 人气%）              │
│ ③ 流派 = 主技能（「不限」默认 + Top 主技能）      │
│ ④ 装备类型 10 个中文 tab（头盔…药水）             │
│ ⑤ 流行装备 Top20 chips（暗金金色）点亮=选中        │
│    └ 普通基底选中 → 热门词条 Top10 chips 点亮     │
│ footer: 填入市集并搜索（现有 P2_FILL 链路）        │
└──────────────────────────────────────────┘
```

- 样式/尺寸与经典模式一致（市集深色 token，同 header/footer）。
- 切换开关持久化到 chrome.storage（下次打开记住模式）。
- 词条 chip 显示「中文名 + 占比」；点亮后可选填最小/最大（默认留空=只筛存在）。

## 5. 填表链路

- **单部位填入**：市集一次搜索只能一个物品分类，进阶模式点「填入」只提交当前展示部位（部位内多个词条/装备基底条件正常多组填入）。跨部位需用户逐部位搜索——与市集行为一致。
- 暗金装备选中 → 复用 `renderUniqueBlocks`（固定词条自动带出）。
- 普通装备+词条 → 组装 `affixes` payload，`content.js` 零改动。

## 6. 映射表（抓取脚本内置，人工可校正）

1. 职业：Warrior→战士、Monk→武僧、Ranger→游侠、Mercenary→佣兵、Sorceress→女术士、Witch→女巫、Druid→德鲁伊（+ Huntress→猎手 等）。
2. 升华：Gemling Legionnaire→宝石军团士兵 等国服译名（31 条）。
3. 技能（流派展示名）：热门技能 ~100 条，缺失回退英文。
4. 装备类型：头盔→Helmets、护甲→Body_Armours、手套→Gloves、鞋→Boots、项链→Amulets、戒指→Rings、腰带→Belts、咒符→Charms、药水→Life_Flasks+Mana_Flasks、武器→12 武器 baseSlug 汇总。
